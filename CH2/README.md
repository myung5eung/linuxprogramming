# 과제
### 리눅스 명령어가 무엇인지 설명하시오. 또, 실제 명령어의 정체는 무엇인가?
리눅스 명령어는 사용자가 운영체제에게 특정 작업을 수행하도록 지시하는 단어로, 터미널에 입력한 뒤 Enter 키를 누르면 실행된다.
실제 명령어의 정체는 운영체제의 특정 디렉터리에 미리 저장되어 있는 컴퓨터가 실행할 수 있는 실행파일(프로그램)이다.

### 리눅스에서 가장 많이 사용되는 명령어 10개를 조사하고 설명하시오. 또 셸에서 실행하고 결과를 첨부하시오.
1) ls: 현재 디렉터리의 파일 및 디렉터리 목록을 출력한다.
2) cd: 사용자의 현재 작업 디렉터리를 변경한다.
3) pwd: 현재 작업 중인 디렉터리의 절대 경로를 출력한다.
4) mkdir: 새로운 디렉터리를 생성한다.
5) clear: 터미널 화면의 기존 출력 내용을 모두 지운다.
6) rm: 파일이나 디렉터리를 삭제한다.
7) cp: 원본 파일이나 디렉터리를 다른 위치나 이름으로 복사한다.
8) mv: 파일이나 디렉터리를 이동하거나, 이름을 변경할 때 사용한다.
9) cat: 파일의 내용을 터미널 화면에 텍스트로 출력한다.
10) man: 특정 명령어의 사용법 및 옵션을 설명하는 매뉴얼을 출력한다.

### 셸과 커널을 구분하여 자세히 설명하시오.
셸: 사용자와 커널 사이의 인터페이스 역할로 사용자가 터미널을 통해 텍스트 명령어를 입력하면 셸이 이를 해석하여 컴퓨터가 이해할 수 있는 기계어 형태로 변환해 전달한다.
커널: 리눅스 운영체제의 핵심 부분으로 하드웨어를 직접 제어, 셸로부터 전달받은 명령을 바탕으로 CPU, 메모리 할당, 프로세스 관리 등 시스템의 실제적인 작업을 수행한다.

### 프롬프트 문자열에서 문자 ~의 의미를 조사하라.
프롬프트에서 ~ 기호는 현재 로그인한 사용자의 홈 디렉터리를 의미한다.
예를 들어 linux@DESKTOP:~$ 라는 프롬프트에서는 현재 작업 위치가 해당 사용자(linux)의 기본 홈 디렉터리임을 나타낸다. 

### sh, bash, zsh 셸의 차이를 자세히 조사하시오.
| 셸    | 특징                           |
| ---- | ---------------------------- |
| sh   | UNIX의 기본 셸로 사용되었으며 구조가 단순/사용자 편의 기능 부족   |
| bash | sh와 호환되며 Linux의 표준 셸로 많이 사용/명령어 기억, 방향키, 자동완성 등 지원 |
| zsh  | 다양한 편의 기능을 제공하며 macOS의 기본 셸/뛰어난 경로 완성 및 교정 기능 제 |


### 셸 스크립트에 대하여 자세히 조사하시오.
셸 스크립트는 셸에서 일일이 입력해야 하는 여러 명령어들을 텍스트 파일에 미리 작성해 두고 셸이 그 파일에 적힌 명령어들을 순차적으로 읽어 한 번에 실행하게 만드는 프로그램이다.

### Windows에서 사용하는 CLI방식의 셸의 종류를 조사하라.
- CMD: 과거 MS-DOS 시절부터 이어져 온 Windows의 가장 기본적인 CLI 셸이다.
- PowerShell: 기존 CMD의 한계를 극복하기 위해 만들어진 강력한 객체 지향 셸로 복잡한 Windows 시스템 관리와 자동화 작업을 수행할 수 있다.
- WSL: Windows 환경에서 가상머신 없이도 Linux용 기본 셸과 명령어들을 네이티브하게 실행할 수 있도록 지원하는 환경이다.
