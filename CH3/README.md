# 3-1 실습과제 
| 기능 | 단축키 |
|---|---|
| 문자단위 커서이동 → 앞, 뒤, 맨앞, 맨뒤 | Ctrl+b, Ctrl+f, Ctrl+a, Ctrl+e |
| 단어단위 커서 이동 → 앞, 뒤 | Meta(alt)+b, Meta(alt)+f |
| 현재 위치 문자 삭제 | Delete, Ctrl+d |
| 뒤에 있는 문자 삭제 | Backspace, Ctrl+h |
| 뒤에 있는 단어 삭제 | Ctrl+w |
| 자르기 및 붙여넣기 | Ctrl+k, Ctrl+u / Ctrl+y |
| 화면 잠금 및 해제 | Ctrl+s / Ctrl+q |
| 실행종료 | Ctrl+c |
| 화면삭제 | Ctrl+l |
