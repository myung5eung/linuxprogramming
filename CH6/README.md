- 다음 2가지 명령어의 차이는 무엇인가?
$ find . -name ‘*.txt’
$ find . -name *.txt
 ' '가 있으면 명령어(find)가 *을 해석하여 확장자가 .txt인 모든 파일을 찾아주고 없으면 셸이 먼저 해석하여 .txt 확장자인 모든 파일을 인자로 주게되어 오류가 날 수 있다.
