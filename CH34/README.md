# 실습과제 1
### make, Makefile을 구분하여 차이점을 설명하라
- make: Makefile의 내용을 해석하여 프로그램의 컴파일과 링크 과정을 자동으로 수행하는 빌드 자동화 도구이다.
- Makefile: 프로그램을 컴파일하고 링크하는 방법을 작성해 놓은 빌드 설정 파일이다.

### 프로그램 개발과정에서 GNU Make는 왜 필요한가?
- 소스코드를 빌드할 때 사용자가 컴파일과 링크 명령어를 직접 반복하여 입력하는 과정을 자동화, 파일의 생성 시간을 비교하여 변경된 파일과 관련된 부분만 다시 빌드할 수 있다.

### 윈도우에서 사용한 Visual Studio에서는 make의 역할을 누가 하는가?
- Visual Studio에서는 MSBuild가 프로젝트의 빌드 설정을 읽고 컴파일과 링크 등의 빌드 과정을 자동으로 수행
