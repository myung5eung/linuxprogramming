# 실습과제1
### 정적라이브러리와 동적라이브러리의 차이를 설명하라 -> 정의, 링크시점, 장단점 등
정적 라이브러리는 링크 단계에서 라이브러리 코드가 실행파일에 포함되는 방식이다. 실행파일의 크기는 커지지만 실행 시 별도의 라이브러리 파일이 필요하지 않다.

동적 라이브러리는 실행 시 필요한 라이브러리를 로드하여 사용하는 방식이다. 실행파일의 크기가 작고 여러 프로그램에서 라이브러리를 공유할 수 있지만, 실행 시 해당 라이브러리가 필요하다.

### gcc의 -I, -l, -L, -g, -v 옵션의 기능을 설명하라
-I: 헤더파일의 경로를 지정
-l: 사용할 라이브러리 파일을 지정
-L: 라이브러리 파일의 경로를 지정
-g: 디버그 모드로 컴파일
-v: GCC 실행 과정에서 수행되는 명령어를 출력

### 빌드 모드인 디버그모드(-g 옵션)와 릴리즈 모드(-O1,2,3 옵션)의 차이를 설명하라
디버그 모드: -g 옵션을 사용하여 디버깅에 필요한 정보를 포함해 컴파일하는 방식이다. 프로그램의 오류를 확인하고 수정할 때 사용한다.

릴리즈 모드: -O1, -O2, -O3 등의 최적화 옵션을 사용하여 프로그램을 최적화하는 방식이다. 숫자가 높아질수록 더 높은 수준의 최적화를 수행한다.
