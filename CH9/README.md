# 실습과제 3
- 리눅스에서 관리자 권한이 필요한 경우에 대하여 조사하라.
시스템 설정 파일을 수정하는 경우, 새로운 프로그램이나 패키지를 설치하는 경우, 일반 사용자가 접근할 수 없는 시스템 파일을 읽거나 수정하는 경우, 다른 사용자가 소유한 파일의 권한을 변경하거나 관리해야 하는 경우, 시스템 전체에 영향을 주는 관리 작업을 수행하는 경우 등 관리자 권한이 필요하다.<br>

- 파일 퍼미션과 디렉터리 퍼미션의 의미의 차이점을 비교 설명하라.
파일: `r`, `w`, `x`는 각각 읽기, 쓰기, 실행 권한을 의미
디렉터리: 각각 파일 목록 확인, 파일 생성·삭제, 디렉터리 이동 및 내부 접근을 의미

- Su명령어와sudo 명령어의 차이를 설명하라.
`su`: 슈퍼 사용자로 전환하여 exit할 때까지 관리자 권한을 유지하는 명령어
`sudo`: 특정 명령어 하나만 관리자 권한으로 실행하고 끝나면 일반 사용자로 돌아오는 명령어
