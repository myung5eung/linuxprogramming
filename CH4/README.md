# 실습과제 1

다음 단어 또는 기호의 의미를 설명하라.
- 디렉터리: 여러 개의 파일을 모아 놓은 파일
- 서브 디렉터리: 어떤 디렉터리 안에 포함되어 있는 디렉터리
- 작업 디렉터리: 현재 사용자가 위치하여 작업하고 있는 디렉터리
- 홈 디렉터리: 사용자별로 할당되는 개인용 디렉터리
- `~`: 현재 사용자의 홈 디렉터리를 나타내는 기호
- `.`: 현재 작업 디렉터리를 의미하는 기호
- `..`: 현재 작업 디렉터리의 부모 디렉터리를 의미하는 기호
- `/`: 루트 디렉터리를 의미하며, 경로에서 디렉터리를 구분할 때도 사용
- 상대경로: 현재 작업 디렉터리를 기준으로 파일이나 디렉터리의 위치를 나타내는 경로
- 절대경로: 루트 디렉터리 `/`부터 시작하여 파일이나 디렉터리의 전체 위치를 나타내는 경로
