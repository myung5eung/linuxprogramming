# 실습과제
### ls 명령어의 4가지 옵션 -a, -l, -F, --help을 설명하고 각각 실행 예를 첨부하시오.
- -a: 숨겨진 파일도 함께 파일항목 출력
- -l: 파일의 상세 정보 출력
- -F:파일의 종류를 의미하는 기호를 추가해 출력
- --help: 명령어 매뉴얼을 출력
  
### 경로확장 문자 *, ?의 의미를 설명하고 각각 실행예를 첨부하시오.
와일드 카드 확장자라고 불리며
- *: 임의의 문자열을 의미
- ?: 임의의 한 문자를 의미
