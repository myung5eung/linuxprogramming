# 과제
## 가상머신이란 무엇인가?
가상머신은 가상화 소프트웨어를 이용하여 물리적인 하드웨어가 아닌 소프트웨어적으로 구현한 가상의 컴퓨터이다. 컴퓨터 한 대 안에서 CPU, 메모리, 저장공간 등의 자원을 분할하여 또 다른 독립적인 컴퓨터가 있는 것처럼 사용할 수 있게 해주고 Windows PC 안에서 가상머신을 띄워 Linux를 실행하는 것이 가능하다.
## 가상머신을 사용하는 이유를 설명하라.
가상머신을 사용하면 하나의 실제 컴퓨터에서 여러 운영체제를 동시에 사용할 수 있다. Windows 컴퓨터에 Linux를 직접 설치하려면 하드디스크 파티션을 분할하거나 멀티부팅 환경을 구성해야 하는데, 이 과정에서 기존 시스템이 손상될 위험이 있다. 하지만 가상머신을 사용하면 호스트(기존 Windows) 환경과 게스트(가상머신 내 Linux) 환경이 논리적으로 완전히 분리되기 때문에, 가상머신에 문제가 생겨도 기존 Windows 시스템에는 영향을 주지 않아 보다 안전하고 편리하게 다양한 운영체제 환경을 구축하고 테스트할 수 있다.
## WSL2가 다른 가상머신 소프트웨어와 비교하여 장점이 무엇인가?
Microsoft에서 만든 경량 유틸리티 가상머신 기반 구조를 가진다. VirtualBox나 VMware 같은 전통적인 가상머신에 비해 다음과 같은 강력한 장점이 있다.
1) 메모리와 CPU 자원을 고정적으로 할당받지 않고 필요한 만큼만 동적으로 할당하므로 호스트 PC의 자원 소모가 적고 부팅 속도가 압도적으로 빠르다.
2) 실제 Linux Kernel을 탑재하여 완벽한 호환성을 제공하므로 Docker나 각종 리눅스 전용 프로그램들이 윈도우 환경에서 원활하게 동작한다.
3) Windows 파일 시스템과 완벽하게 연동되어, VS Code와 같은 윈도우용 개발 도구에서 리눅스 내부 파일에 직접 접근하여 코드를 작성하고 디버깅하기가 매우 편리하다.

## GUI, CLI의 장단점을 비교 설명하시오.
- GUI: 아이콘, 버튼, 그림 등 그래픽 요소를 이용하여 컴퓨터를 사용하는 방식이다. 직관적이고 시각적이어서 컴퓨터 지식이 부족한 초보자도 쉽게 배울 수 있지만 그래픽 화면을 구현하기 위해 메모리와 그래픽 처리 장치 등 시스템 자원을 많이 소모하며, 대량의 반복 작업을 수행하기에는 비효율적이다.
- CLI: 사용자가 키보드로 명령어를 입력하고 그 결과를 텍스트로 확인하는 방식이다. 텍스트 기반이라 가볍고 처리 속도가 빠르며, 쉘 스크립트를 통해 복잡한 반복 작업을 손쉽게 자동화할 수 있지만 텍스트 명령어를 미리 암기해야 하고 시각적 피드백이 부족하여 초보자가 접근하기 어렵다.

## CLI방식의 인터페이스가 GUI방식보다 처리속도가 빠른 이유를 설명하라.
GUI는 아이콘, 이미지, 창 등의 화려한 그래픽 정보를 끊임없이 화면에 렌더링하고 표시해야 하므로 많은 컴퓨터 자원(CPU, GPU, RAM)과 데이터를 처리해야 한다. 반면 CLI는 명령어와 실행 결과를 단순한 텍스트 문자로만 주고받기 때문에 처리해야 하는 연산량과 데이터의 크기가 훨씬 작다. 특히 서버 관리를 위해 네트워크로 원격 접속을 할 때, 무거운 그래픽 데이터를 전송해야 하는 GUI에 비해 CLI는 가벼운 텍스트만 전송하므로 네트워크 대역폭 소모가 적어 훨씬 빠르고 쾌적하게 작업할 수 있다.
## 리눅스에서는 왜 CLI방식을 주로 사용하는가?
Linux는 주로 데이터 센터 등에 위치한 서버 컴퓨터의 운영체제로 많이 사용되며, 관리자는 이를 원격으로 접속하여 제어한다. GUI 환경을 원격으로 사용하면 그래픽 화면 데이터를 네트워크로 전송해야 하므로 통신량이 많아져 응답 속도가 느려진다. 반면 CLI는 텍스트만 주고받아 원격지에서도 지연 없이 빠른 작업이 가능하다.
또한, 서버 환경에서는 수많은 설정이나 수백 대의 컴퓨터를 관리하기 위해 '작업의 자동화'가 필수적인데, CLI 환경에서는 쉘 스크립트를 작성하여 이를 매우 효율적으로 처리할 수 있기 때문이다. vi, gcc, make 등 강력한 개발 도구들이 모두 CLI에 최적화되어 있다는 점도 큰 이유이다.

## 리눅스 명령어란 무엇이고 중요 5개 명령어를 조사하라. 실행결과를 첨부하라
리눅스 명령어는 CLI 환경에서 사용자가 운영체제에게 특정 작업을 수행하도록 지시하기 위해 약속된 텍스트 기반의 명령이다. Terminal에 명령어를 입력하고 Enter 키를 누르면, 쉘이 이를 해석하여 커널에 전달하고 실행 결과를 다시 화면에 텍스트 형태로 출력해 준다.
1) pwd: 사용자가 위치해 있는 작업 디렉터리(폴더)의 절대 경로를 화면에 출력한다
2) ls: 현재 디렉터리나 지정한 디렉터리 내에 있는 파일과 하위 폴더의 목록을 보여준다.
3) cd: 사용자의 현재 작업 디렉터리를 다른 곳으로 이동시킬 때 사용한다
4) mkdir: 새로운 디렉터리(폴더)를 생성할 때 사용하는 명령어다.
5) ifconfig:시스템에 장착된 네트워크 인터페이스(랜카드)의 설정을 확인하거나 IP 주소, MAC 주소 등의 네트워크 상태를 출력한다
