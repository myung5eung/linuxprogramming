# 과제
## 가상머신이란 무엇인가?
가상머신은 가상화 소프트웨어를 이용하여 소프트웨어적으로 구현한 가상의 컴퓨터이다. 컴퓨터 한 대 안에서 CPU, 메모리, 저장공간 등의 자원을 이용하여 또 다른 컴퓨터가 있는 것처럼 사용할 수 있다. Windows를 사용하면서 가상머신 안에서는 Linux를 사용하는 것도 가능하다.
## 가상머신을 사용하는 이유를 설명하라.
가상머신을 사용하면 하나의 실제 컴퓨터에서 여러 운영체제를 사용할 수 있다. 예를 들어 Windows가 설치된 컴퓨터에 Linux를 직접 설치하려면 하드디스크를 분할하거나 멀티부팅 환경을 구성해야 해야하는데 설정 과정에서 기존 환경에 문제가 생길 수도 있다.
가상머신을 사용하면 기존 Windows 환경을 유지하면서 가상의 컴퓨터에 Linux를 설치할 수 있기 때문에 보다 안전하고 편리하게 여러 운영체제를 사용할 수 있다.

## WSL2가 다른 가상머신 소프트웨어와 비교하여 장점이 무엇인가?
WSL2는 Microsoft에서 만든 경량 유틸리티 가상머신이다. WSL2는 실제 Linux Kernel을 사용하기 때문에 Linux와의 호환성이 높다. Docker나 Linux 프로그램 등을 Windows 환경에서도 사용할 수 있다. 다른 가상머신 소프트웨어인 VirtualBox나 VMware와 비교하면 메모리와 CPU를 필요한 만큼 동적으로 할당하기 때문에 자원 소모가 적고 Windows 파일 시스템과 연동할 수 있다. 또 VS Code와 같은 Windows 개발 도구에서도 Linux 내부의 파일을 직접 수정하거나 디버깅할 수 있다는 장점이 있다.

## GUI, CLI의 장단점을 비교 설명하시오.
- GUI: 아이콘, 버튼, 그림 등 그래픽 요소를 이용하여 컴퓨터를 사용하는 방식이다.
- CLI: 사용자가 키보드로 명령어를 입력하고 그 결과를 텍스트로 확인하는 방식이다.
| 구분 | GUI | CLI |
|---|---|---|
| 장점 | 직관적이고 사용하기 쉬움 | 빠르고 적은 데이터로 작업 가능 |
| 단점 | 많은 시스템 자원과 통신 데이터가 필요할 수 있음 | 명령어를 알아야 해서 처음 사용하기 어려움 |
