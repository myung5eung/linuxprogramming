# 과제
## UNIX 운영체제에 대하여 조사하시오.
UNIX는 1969년 미국 Bell 연구소에서 개발된 운영체제다. 초기에는 어셈블리어로 만들어졌으나 이후 고급 언어인 C언어로 재작성되어 하드웨어에 종속되지 않는 뛰어난 이식성을 갖게 되었다. 이는 이후 등장한 Linux와 macOS 등 여러 운영체제에 큰 영향을 주었다. 다중 사용자와 다중 작업을 지원하여 여러 사람이 하나의 시스템 자원을 공유하고 여러 프로그램을 동시에 실행할 수 있으며 현재 표준으로 쓰이는 계층적 트리 구조의 파일 시스템을 도입한 것이 특징이다.

## Linux, Windows, macOS 를 비교 설명하시오.
- Linux는 누구나 무료로 사용할 수 있고 소스코드가 공개된 오픈소스 운영체제다. 가볍고 안정성이 뛰어나며 사용자 입맛에 맞게 수정이 가능해 주로 개발자나 서버 환경에서 많이 사용된다.
- Microsoft에서 개발한 상용 운영체제로 개인용 컴퓨터에서 가장 널리 사용된다. 직관적인 GUI 환경과 압도적으로 많은 응용프로그램을 지원하여 일반 사용자가 사용하기 가장 편리하다.
- macOS는 Apple에서 개발한 Apple 컴퓨터 전용 운영체제이며 UNIX 계열의 운영체제이다.

## 우분투(Ubuntu) 리눅스에 대하여 조사하시오.
Linux는 원래 리누스 토발스가 개발한 Linux Kernel을 의미했는데 Kernel은 운영체제의 중심에서 CPU, 메모리, 저장장치 등의 하드웨어를 제어하는 역할을 담당한다.
하지만 Kernel만으로는 일반 사용자가 컴퓨터를 사용하기 어렵기 때문에 Linux Kernel에 기본 명령어, 라이브러리, 응용프로그램 등을 묶어서 사용할 수 있도록 만든 것을 Linux 배포판이라고 한다. Ubuntu는 여러 Linux 배포판 중 하나이다.

## 임베디드 시스템용 운영체제로 리눅스가 적합한 이유를 설명하라.
1. 무료로 사용할 수 있는 오픈소스 운영체제다.
2.  비교적 가볍다. Windows와 비교하여 낮은 사양의 컴퓨터에서도 사용할 수 있기 때문에 하드웨어 자원이 제한적인 임베디드 시스템에 적합하다.
3. Linux는 필요한 기능에 맞게 구성하여 사용할 수 있다. 임베디드 시스템은 제품마다 필요한 기능이 다르기 때문에 불필요한 기능을 줄이고 필요한 기능 중심으로 시스템을 구성하기에 적합하다.
4. Linux는 다양한 하드웨어와 네트워크 환경을 지원한다.
